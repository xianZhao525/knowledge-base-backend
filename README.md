# knowledge-base-backend
一个面向团队内部的知识库管理系统，支持用户登录、文档管理和权限控制，后端基于 Spring Boot 构建，提供标准 REST API。

📖 项目简介
事先声明：项目代码中含有大量注解是因为该项目为边学习边实践的Spring Boot项目。
本项目是一个 前后端分离的内部知识库管理系统，主要用于团队内部的技术文档、业务文档等知识沉淀与管理。
系统支持用户登录鉴权、文档的创建与管理，并通过权限控制和缓存机制提升系统的安全性和性能。
该项目以 后端工程实践 为核心，重点关注接口设计、系统结构和基础性能优化。

🧩 核心功能
用户登录与身份认证（JWT）
基于角色的权限控制
知识文档的创建、编辑、删除与查看
文档列表分页查询
基础缓存优化（Redis）
统一异常处理与接口返回格式

🛠 技术栈
Java 8+
Spring Boot
MyBatis / MyBatis Plus
MySQL
Redis
Maven

项目启动
在终端进入项目目录
cd knowledge-base
输入启动命令：
mvn spring-boot:run
